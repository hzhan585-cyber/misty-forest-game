# Environment background assets

These five 1600×900 WebP plates were generated with the built-in image generation tool from the player's environment moodboard as a style reference. They are new compositions rather than crops of the reference board.

Shared direction: wide 16:9 Minecraft-inspired voxel dark-fantasy side-scroller environment; cold teal mist, ruined block architecture, wet reflective stone, restrained warm lanterns, a readable central combat corridor, and no characters, creatures, UI, text, watermark, or interactive foreground floor.

- `forest-entrance.webp`: mossy ruined gate, lanterns, distant bridges, waterfalls and towers.
- `deep-woods.webp`: immense trunks, hanging vines, elevated walkways, watchtowers and a distant waterfall.
- `webbed-grove.webp`: layered pale webs and cocoons around ruined forest structures with silver-cyan backlight.
- `abandoned-caravan.webp`: overturned wagon, scattered crates, campfire, mountain road and distant aqueduct ruins.
- `king-spider-nest.webp`: symmetrical red-black royal nest, monumental ruins, hanging webs, ember fissures and a throne-like arch.
