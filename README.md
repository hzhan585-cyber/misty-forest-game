# 《晨曦传记：迷雾森林》灰盒原型

这是一个使用 Phaser 3 制作的横版动作探索游戏原型。是以Minecraft同人漫画《晨曦传记》为原型制作的三创游戏。目前阶段只验证核心操作和 Reward-Damage-End 循环，不包含正式角色形象。

## 当前内容

- Minecraft 兼容的可拆分方块白模骨架，头、躯干、左右手脚和武器挂点均可独立运动
- 开始界面可导入本地 64×32 或 64×64 Minecraft PNG 皮肤，也可启用 UV 彩色测试皮肤或恢复白模
- 皮肤只在当前浏览器本地读取与保存，不会上传；重新打开游戏后仍会自动应用
- 左右移动、二段跳、空中斩和可随时取消攻击的无敌帧闪避
- 横斩 → 纵斩 → 强力终结攻击的三段地面连击
- 消耗 30 能量、冷却 1.1 秒且无前摇的范围技能
- 蜘蛛会先以金色眼睛提示攻击，再扑咬并进入恢复阶段；普通接触不再造成伤害
- 敌人血条、受击闪烁、击退和镜头震动反馈
- 三段攻击具有对应覆盖范围的剑光拖尾；后两段正面距离不会小于第一段
- 白模拥有待机呼吸、跑步摆臂、起跳/下落姿势、蜷身闪避、三段攻击身体重心、空中攻击和技能展开动作
- 攻击动作分为蓄势、快速挥击和收招三个阶段；终结攻击蓄势与收招更重，闪避带短暂残影，落地带方块骨架压缩反馈
- 角色默认采用三分之二侧身显示：正面纹理压窄、朝向侧面扩大，头部和武器前探，后侧肢体降低亮度，左右转向时切换对应侧面纹理
- 蜘蛛锁定攻击时会先出现内收光圈；扑咬前约 280 毫秒再出现明亮释放闪光
- 释放闪光出现时会锁定扑咬方向，之后不会转身追踪正在闪避的玩家
- 四张彼此独立的灰盒区域地图
- 每个区域拥有固定数量、不会刷新的测试蜘蛛
- 杀敌恢复技能能量
- 杀敌有 28% 概率掉落可拾取的生命微光，恢复 1 点生命
- 清除区域后增加 25% 森林探索度，并将该区域永久标记为安全
- 地图之间通过左右边缘的通道切换，可以返回已访问区域
- 怪物只能存在于自己的地图，无法跟随玩家进入其他区域
- 离开未清空区域后，已经击败的敌人不会复活
- 探索度达到 75% 后，在蜘蛛活动区显现隐藏的国王蜘蛛巢入口
- 解锁后 HUD 与金色方向标会指引玩家寻找隐藏入口
- 隐藏入口连接独立的国王蜘蛛首领房，击败首领后完成结局 A
- 国王蜘蛛拥有锁向扑咬、落网区域攻击和可通过跳跃规避的近身横扫，半血后攻击间隔缩短且落网数量增加
- 生命归零与重新开始
- 程序生成的灰盒森林背景，不使用正式美术素材
- 环境视觉采用冷青迷雾、暖色灯火、森林遗迹与潮湿石材的概念方向，并用方块树冠、方块月亮、石砖和分块地表保持 Minecraft 语言
- 场景细节包括断裂木栅栏、藤蔓、断木、缺损石砖、裂缝、苔藓、碎石、草丛、积水反光、蘑菇、补给箱和缓慢漂移的像素雾粒

## 操作

- `A` / `D`：左右移动
- `W` / `Space`：跳跃
- 鼠标左键 / `J`：普通攻击
- `Shift` / 鼠标右键：闪避
- 鼠标中键 / `K`：能量脉冲
- `R`：失败后重新开始

## Minecraft 皮肤

开始界面提供三个皮肤控制：导入本地 PNG、启用 UV 彩色测试皮肤、恢复无皮肤白模。导入器会检查图片必须为 64×32 旧版格式或 64×64 现代格式，并将头部、身体和四肢的正面与侧面裁切到方块骨架。64×32 皮肤的左手和左腿会按照旧版规则镜像复用；64×64 皮肤使用独立左右肢体并读取可用的第二皮肤层。当前第一版按经典四像素宽手臂显示，细手臂切换将在后续加入。

开始界面已经预留可扩展的角色选择区。当前只有“自定义皮肤角色”可用，另外两个角色槽位用于后续正式角色和结局解锁角色。角色选择使用独立 ID 保存，不依赖皮肤文件名。

## 语言与界面

开始界面右上角可在中文和英文之间切换，选择会保存在当前浏览器。开始界面、角色选择、皮肤控制、区域名称、战斗 HUD、目标、引导、奖励、首领名称、失败画面与结局文字均支持双语。

战斗 HUD 使用紧凑的方块风格生命、体力和技能进度条；区域信息集中在右上角。底部操作提示会在进入区域数秒后自动淡出，减少对游戏画面的遮挡。

## 本地运行

1. 安装 Node.js。
2. 在项目目录运行 `npm start`。
3. 打开 `http://127.0.0.1:5173`。

Phaser 3.90.0 已保存在项目的 `vendor/` 目录中，因此运行游戏不需要联网，也不需要安装额外依赖。

不要直接双击 `index.html`；现代浏览器会限制模块文件的本地加载。

## 当前设计约束

- 正式角色名称、能力和解锁条件以设计 PDF 为准。
- 当前白模没有身份，不代表任何正式角色。
- 后续皮肤导入功能将读取合法使用的 Minecraft 皮肤 PNG；不会使用 AI 生成正式角色外观。骨架已预留 64×32 旧版和 64×64 现代皮肤的 UV 映射定义。
- 角色朝右时左侧手脚绘制在躯干前，朝左时右侧手脚绘制在躯干前；躯干夹在远近两组肢体之间，侧面贴图与遮挡关系保持一致。闪避的倾斜与旋转也按朝向完整镜像。
- Moodboard 只用于色彩、氛围、光照和环境方向，不直接作为最终游戏素材。
- 受伤不会打断玩家攻击；闪避可以随时取消正在进行的攻击。
- 闪避拥有约 360 毫秒无敌时间，看到蜘蛛第二次释放闪光后立即闪避可以覆盖攻击时刻。
- 技能数据独立配置，已为蓄力、击杀强化、条件释放和多充能技能预留字段。
- 普通地形障碍必须通过地面的抬升、下降、台阶、坑洼、树根或石块形成，不使用缺乏环境理由且容易卡头的悬空平台。
- 只有木桥、脚手架和遗迹楼层等具有场景意义的结构可以悬空，并必须为角色保留足够的下方净空。

## 当前地图流程

```text
森林入口 ⇄ 深处林地 ⇄ 蜘蛛活动区 ⇄ 破损商队
                           ↓
                 隐藏的国王蜘蛛巢入口
                           ↓
                    国王蜘蛛首领战
                           ↓
                       结局 A
```

每张地图有自己的固定敌人和通道。离开地图时会保存击败记录；返回后只生成尚未击败的敌人。清除一个区域会恢复技能能量和一点生命，并增加 25% 探索度。四个区域中完成任意三个后，蜘蛛活动区会出现隐藏入口及方向指引。进入后切换到宽阔的首领场地，击败国王蜘蛛完成当前版本结局。

## 敌人机制白模

- 砷铅铁寄生蛛：基础近战杂兵，使用锁定方向的正面扑咬。
- 冰霜蜘蛛：只有 1 点生命；保持中远距离，锁定位置后发射冻结蛛网。命中会短暂束缚，闪避可以解除；一旦被近身，普通攻击或技能一次即可击杀。
- 毛蜘蛛：用后腿踢出沿抛物线飞行的毒毛，毒毛落地后留下密集、交错的地面毛刺和污染底色，持续表示危险区域并迫使玩家离开原位。
- 黑寡妇蜘蛛：快速接近并进行毒性突进，命中后产生一次延迟毒伤。
- 奶牛蜘蛛：2 点生命值的召唤杂兵，普通攻击两刀即可击杀；使用快速跳咬，不会作为区域固定敌人生成。
- 国王蜘蛛：保留扑咬、落网和近身横扫，并在两个生命阶段分别从地图左右边缘召唤奶牛蜘蛛。

当前敌人使用颜色、轮廓细节和名称标签区分，目的是先验证组合战斗。正式 Minecraft 方块模型和贴图将在机制稳定后替换白模。
